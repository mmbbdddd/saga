这个是pc后面改进的一版、融合了sagas一致性事务——————蚂蚁原版的是没有分布式事务控制机制的、全靠开发自己控制。优点是简单。在蚂蚁高手如云的地方倒也不会存在多大的问题。

即使自己实现一个可靠的分布式事务也不是多难、只是步骤上比较啰嗦、需要先容错、再执行、再容错。大多数人不会注意到第一个阶段，极端情况下会有一点问题。

考虑到开发任务密度比较高、人员比较杂、就改了pc融合了分布式事务，融合了状态管理。


代码结构上模仿了dubbo，能适配各种框架的扩展。从流程配置、到状态管理、到会话管理、到统计、到插件机制……模仿dubbo的13种扩展，能想的开箱即用的便利都想了
